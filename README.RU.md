# NotiPrint

[English version](README.md)

NotiPrint — локальное Android-приложение, которое сохраняет важные события телефона и печатает их на термопринтере Bluetooth Classic SPP с помощью растровых ESC/POS-команд.

Приложение рассчитано на простой сценарий с крупным текстом: для получения бумажной копии важного события не нужно открывать приложение.

## Возможности

- Печать входящих СМС, пропущенных звонков и уведомлений календаря.
- Сохранение каждого подходящего события в локальную очередь Room до печати и повторная отправка после появления принтера или Bluetooth-соединения.
- Ночной режим: уведомления копятся в заданный интервал и печатаются утром.
- Рендеринг всего содержимого в 384-точечное чёрно-белое изображение, поэтому кириллица не зависит от кодовой страницы принтера.
- Работа с ранее сопряжёнными 58-мм Bluetooth SPP / ESC-POS принтерами, включая 384-точечные модели наподобие MUNBYN IMP006.
- Постоянный foreground-сервис и повторное подключение слушателя уведомлений после запуска приложения или перезагрузки телефона.
- Возможность игнорировать СМС с незнакомых числовых номеров, не отбрасывая буквенные метки отправителя: `МЧС`, `MCHS` и подобные.
- Локальный чёрный список для СМС и пропущенных звонков: можно добавить все номера контакта либо указать номер/метку отправителя вручную.
- Диагностическая тестовая страница для проверки качества печати и покрытия бумаги.

## Требования

- Android Studio с установленным Android SDK.
- Совместимый с проектом Gradle JDK — предпочтительно JDK 17 или JDK 21.
- Телефон с Android 8.0 (API 26) или новее.
- Ранее сопряжённый Bluetooth Classic SPP-принтер с поддержкой растровой печати ESC/POS (`GS v 0`).

## Сборка

Откройте корень проекта в Android Studio. Если нужно, выберите совместимый Gradle JDK в настройках Gradle Android Studio.

Из корня проекта debug APK можно собрать одной из команд:

```powershell
.\gradlew.bat assembleDebug
```

```bash
./gradlew assembleDebug
```

После успешной сборки APK находится по пути:

```text
app/build/outputs/apk/debug/app-debug.apk
```

Параметр `--offline` используйте только если нужные зависимости Gradle уже есть в локальном кэше.

## Установка и первый запуск

Для отладки подключите телефон с включённой USB-отладкой, выберите его в Android Studio и нажмите **Run**.

Чтобы установить APK на обычный телефон, скопируйте `app-debug.apk` на устройство, откройте его через файловый менеджер и разрешите установку из этого источника, когда Android запросит разрешение. USB-отладка для этого не нужна.

При первом запуске:

1. Выдайте доступ к Bluetooth/устройствам поблизости и выберите уже сопряжённый принтер.
2. Запустите «Тестовую печать», чтобы проверить соединение и бумагу.
3. Выдайте запрошенные разрешения на уведомления, СМС, контакты и журнал вызовов.
4. В настройках телефона разрешите NotiPrint автозапуск и работу в фоне. Названия этих настроек зависят от производителя.

## Примечания о принтере

Приложение передаёт одно растровое задание целиком по одному SPP-соединению и выполняет сброс данных после каждого чека. Это уменьшает паузы, которые часто возникают при построчной Bluetooth-печати.

В спецификации MUNBYN IMP006 указана термобумага 58 мм толщиной 0,06–0,08 мм. На плотных чёрных областях на качество печати заметно влияют термочувствительность бумаги и заряд аккумулятора принтера.
